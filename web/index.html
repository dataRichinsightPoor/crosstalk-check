A forward model, not a receptor predictor

        
Two receptor states feed two branch states and a finite active-effector pool. A conformational gate can control one connection, A's allocation, or the full effector drive. Feedback, a history-dependent state, reversible reporting, irreversible recording, and sensor sequestration are explicit.

        
I(t) = YAB − YA − YB + Y0
ΔI = Ireference − Iintervention

        
Interaction depends on the measurement scale. A saturated output can yield a negative interaction contrast without receptor inhibition. Matching a plot does not identify a molecular mechanism.

        
Conformational switching is abstracted
The open fraction relaxes toward the commanded state with separate opening and closing time constants. Residual leak determines the minimum available activity. The model does not design a protein sequence or infer an energy landscape from structure.

        
Numerical implementation
The browser uses bounded-step RK4, split at every input discontinuity. The repository includes an independent SciPy DOP853 implementation and cross-engine fixtures for all 18 examples. Numerical agreement verifies implementation, not biological validity.

        
Reproduce or change this experiment
Export a JSON configuration and run it with crosstalk run --config experiment.json. CSV includes all states and eight matched conditions. All calculations run locally in this page; no simulation inputs are sent to a server.
