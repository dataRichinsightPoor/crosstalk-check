# Is That Receptor Crosstalk, or Did the Assay Create the Interaction?

## Data-Rich, Insight-Poor · No. CCLXVII

99 Small Problems · Installment 08

Two inputs produce a larger response together than either produces alone. That observation is a starting point, not a mechanism: the receptors may cooperate at a shared effector, alter each other's activation, compete for a limited component, or simply pass through the same nonlinear measurement.

Crosstalk Check turns that ambiguity into a set of executable questions. Its purpose is not to predict what a receptor pair will do, but to ask which control would make the explanation identifiable.

## The small problem

An intervention reduces the combined response. Was a specific connection interrupted, or was the common output simply suppressed?

The model makes both possibilities available. A selective connection gate can preserve the isolated inputs by construction; a whole-effector gate generally does not, which is why the single-input controls remain visible beside the combined response.

## The measurement problem

A slow reporter can retain a signal after the underlying activity has fallen. A binding sensor can also change the free activity it is meant to report.

These are separate mechanisms in the tool. The first changes the observation dynamics; the second changes the modeled signaling system itself.

## How to use the example library

Each entry separates a published observation, an explicit abstraction, and what that abstraction leaves out. The receptor studies motivate different mechanisms, but the numerical presets are synthetic and should not be ranked as biological predictions.

The five engineered-comparator or proposed-extension examples are marked separately from the 13 receptor pairs. A geometry context axis or an allosteric-modulator input is not relabeled as a second receptor.

## The practical question

Before interpreting a reduction in the combined output, ask what happened to each receptor's proximal response, the timing of the input, and the measurement process. The useful experiment is the one that preserves enough of the system to isolate the connection being tested.
